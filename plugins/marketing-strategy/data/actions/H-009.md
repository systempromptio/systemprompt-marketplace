## First comment (post immediately after submission)

HN convention is that the submitter posts the first comment with context. Keep it honest and evidence-dense.

```
Hi HN. I built this over the last ~18 months after hitting the same governance problems in
every AI consulting engagement: AI agents running in production with zero visibility, zero
policy enforcement, and zero audit trail. Security teams kept asking "what is our AI doing"
and the answer was always "we'll get back to you."

What it is, in one sentence: a single ~50MB compiled Rust binary that sits between AI agents
and every tool they can call, runs a synchronous four-layer governance pipeline (scope check,
secret detection, blocklist, rate limit) on every tool call before it executes, and emits
full audit events as structured JSON for your SIEM. Identity propagates end-to-end from the
user through the agent to the tool call to the result, linked by trace_id.

What it is not: a SaaS. There is no cloud service. You clone the template, compile the binary,
run it on your own infrastructure against your own PostgreSQL, and own the extension code.
BSL-1.1 source-available. Air-gap capable. Provider-agnostic (works with Anthropic, OpenAI,
Google Gemini, local models).

How it compares to recent entrants:
- Microsoft Agent Governance Toolkit (April 2026, MIT) is a toolkit — framework-agnostic,
  sub-ms policy enforcement, 9500+ tests. Everything I built above the pipeline (dashboard,
  user management, skill marketplace, SIEM integration, audit UI) you assemble yourself.
- Rubrik Agent Govern is SaaS tied to Rubrik infra.
- Claude Enterprise is native but Claude-only and SaaS-only.
- MCP gateways (MintMCP, TrueFoundry, Lunar MCPX) are proxy layers, not full governance.

What I'd love feedback on: (1) the clone-and-run onboarding — does it actually run in under
10 minutes for you? (2) the MCP-native architecture — we embed governance in the transport
layer rather than proxying, and I'm curious if that's the right call for your use case.
(3) anything obvious I'm missing in the comparison above.

Template (clone to try): https://github.com/systempromptio/systemprompt-template
Rust crate: https://github.com/systempromptio/systemprompt-core
Website: https://systemprompt.io

Happy to answer questions.
```

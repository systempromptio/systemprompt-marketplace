## Draft PR body

```markdown
Adding `systemprompt-core`, the Rust crate that powers systemprompt.io — a self-hosted AI governance platform that sits at the MCP transport layer rather than above it.

**What it provides:**
- MCP-native governance: the protocol transport IS the governance layer, not a proxy sitting in front
- Synchronous four-layer tool-call pipeline (scope, secret detection, blocklist, rate limit) evaluated before execution
- Six-tier RBAC with department scoping
- Full audit trail (16 event hooks, 5-point trace from identity to tool to result to cost)
- Structured JSON events ready for SIEM ingestion (Splunk/ELK/Datadog)
- Per-server OAuth2 governance

**What it is:** a Rust library crate you build into a single ~50MB binary. PostgreSQL is the only dependency. Provider-agnostic (Anthropic, OpenAI, Google, local models). Air-gap capable. BSL-1.1 source-available.

**Template for evaluation (clone-and-run):** https://github.com/systempromptio/systemprompt-template — boots the full binary with demo data in under 10 minutes, including MCP server governance demos.

**Crate:** https://github.com/systempromptio/systemprompt-core
**Crates.io:** https://crates.io/crates/systemprompt-core

Not affiliated with Anthropic. Maintained by systemprompt.io.
```
